# DriverBackupTool (Windows 驱动备份与按序智能安装工具)

纯 C 语言 + Win32 原生 API 开发的 Windows 驱动智能备份与按序自动化安装工具。

- **零第三方运行库依赖**：无 .NET、无 Electron、无 Python，单文件绿色版仅 **271KB**；
- **内置 UAC 管理员提权清单**：双击自动引导管理员权限；
- **智能驱动深度策略与体积预估**：支持“最小救命集 / 标准装机集 / 完整镜像集”；
- **缺失驱动自动扫描与智能匹配**：自动抓取黄色感叹号硬件并精准关联备份包；
- **按序自动安装**：免去设备管理器一个个点击，自动遵循“总线 -> 网络 -> 图形 -> 外设”层级批量注入。

---

## 🎯 备份深度等级说明与体积预估

| 深度等级 | 包含硬件类别 | 典型体积范围 | 推荐适用场景 |
| :--- | :--- | :--- | :--- |
| 🟢 **最小救命集** | **有线/无线网卡 + 主板总线芯片组 + 工控专用板卡** | **约 100 ~ 300 MB** | 极速装机，只要能连上网、能通串口/工控卡即可 |
| 🟡 **标准装机集 (推荐)** | **核心芯片组 + 网络 + 声卡 + 核显 + 工控卡** *(排除数GB独显)* | **约 0.8 ~ 1.8 GB** | 办公、工控机、轻薄本日常重装最推荐 |
| 🔴 **完整镜像集** | **全量第三方硬件驱动** *(包含大型 NVIDIA / AMD 独立显卡)* | **约 2.5 ~ 4.5 GB** | 游戏本、图形工作站离线完整封包 |

## 🛠️ 本地编译构建

### Linux 交叉编译（MinGW-w64）
```bash
sudo apt-get install -y mingw-w64
x86_64-w64-mingw32-windres app.rc -O coff -o app.res
x86_64-w64-mingw32-gcc -O2 -municode -mwindows main.c app.res -o DriverBackupTool.exe -lcomctl32 -lshell32 -lole32
```

### Windows 本地构建（MSVC 或 GCC）
* 使用 Visual Studio 开发者命令行或 MinGW 编译即可。

## 📦 自动化 CI/CD
本项目配置了 GitHub Actions 自动化工作流：
* **自动测试**：检查 PE 架构、导入表与子系统依赖；
* **自动构建**：全自动编译出纯净 x64 原生单文件可执行程序；
* **自动发布**：Push 到 `main` 分支或打 `v*` 标签时自动创建 GitHub Release 并附带编译产物供直接下载。
